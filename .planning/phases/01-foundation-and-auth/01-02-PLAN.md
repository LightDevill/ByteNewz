  <files>supabase/migrations/20261018000001_initial_profiles_and_rls.sql, src/types/database.types.ts</files>

  <action>
    Author `supabase/migrations/20261018000001_initial_profiles_and_rls.sql`:
    1. Table `public.profiles`:
       - `id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE`
       - `username TEXT UNIQUE NOT NULL CHECK (username ~ '^[a-z0-9_]{3,30}$')`
       - `display_name TEXT NOT NULL CHECK (length(trim(display_name)) BETWEEN 1 AND 50)`
       - `bio TEXT CHECK (bio IS NULL OR length(bio) <= 250)`
       - `avatar_url TEXT CHECK (avatar_url IS NULL OR (avatar_url ~* '^https://[^\s/$.?#].[^\s]*$' AND length(avatar_url) <= 1000))`
       - `website_url TEXT CHECK (website_url IS NULL OR (website_url ~* '^https://[^\s/$.?#].[^\s]*$' AND length(website_url) <= 500))`
       - `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
       - `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
       *Note: Strictly zero sensitive fields (email, password, roles, permissions) are stored in public.profiles.*

    2. Collision-safe username generator function:
       - Create `public.generate_unique_username(base_name TEXT, user_id UUID)`:
         - Declares `SECURITY DEFINER SET search_path = public, pg_temp;` (with `pg_temp` last).
         - Cleans input to lowercase `[a-z0-9_]`, truncating to 20 chars. Defaults to `'user'` if empty or < 3 chars.
         - Loop up to 5 iterations: appends `'_' || substr(md5(random()::text || clock_timestamp()::text), 1, 5)`.
         - If all 5 attempts collide, deterministic fallback using UUID: `'u_' || substr(replace(user_id::text, '-', ''), 1, 28)` (guarantees uniqueness without crashing the transaction).
       - Revoke public execution: `REVOKE ALL ON FUNCTION public.generate_unique_username(TEXT, UUID) FROM PUBLIC, anon;`

    3. Resilient `handle_new_user()` trigger function:
       - Marked `SECURITY DEFINER SET search_path = public, pg_temp;` (schema-qualifies `public.profiles`).
       - Primary flow:
         - Derives base username from `NEW.raw_user_meta_data->>'username'` or email prefix.
         - Cleans display name from `NEW.raw_user_meta_data->>'display_name'` or fallback to username.
         - Generates username via `public.generate_unique_username(base_name, NEW.id)`.
         - Inserts into `public.profiles (id, username, display_name)`.
       - Failure handling:
         - Wrapped in `BEGIN ... EXCEPTION WHEN OTHERS THEN`:
           Logs warning: `RAISE WARNING 'handle_new_user failed for user %: %', NEW.id, SQLERRM;`
           Attempts secondary fallback insert:
           `INSERT INTO public.profiles (id, username, display_name) VALUES (NEW.id, 'u_' || substr(replace(NEW.id::text, '-', ''), 1, 28), 'User') ON CONFLICT (id) DO NOTHING;`
           If this also fails, logs warning and allows `auth.users` insert to proceed. (Client-side JIT recovery handles delayed profile creation).
       - Revoke public execution: `REVOKE ALL ON FUNCTION public.handle_new_user() FROM PUBLIC, anon;`

    4. Idempotent JIT recovery RPC (`public.ensure_profile_exists()`):
       - Declares `SECURITY DEFINER SET search_path = public, pg_temp;`
       - Takes NO client-provided user ID argument; strictly binds caller ID: `caller_id := auth.uid();`
       - If `caller_id IS NULL`, raises `EXCEPTION 'Unauthorized: No active session'`.
       - Read check: `SELECT * INTO v_profile FROM public.profiles WHERE id = caller_id;`
       - If found, returns existing `v_profile` without modifying any fields (cannot alter existing profile data).
       - If missing, inserts fallback profile:
         `INSERT INTO public.profiles (id, username, display_name) VALUES (caller_id, public.generate_unique_username('user', caller_id), 'User') ON CONFLICT (id) DO NOTHING RETURNING * INTO v_profile;`
       - Returns `v_profile`.
       - Privilege Grant:
         `REVOKE ALL ON FUNCTION public.ensure_profile_exists() FROM PUBLIC, anon;`
         `GRANT EXECUTE ON FUNCTION public.ensure_profile_exists() TO authenticated;`

    5. Immutable identity protection trigger:
       - Function `public.protect_profile_fields()`:
         - `SECURITY DEFINER SET search_path = public, pg_temp;`
         - `IF NEW.id <> OLD.id THEN RAISE EXCEPTION 'Profile ID is immutable'; END IF;`
         - `IF NEW.created_at <> OLD.created_at THEN RAISE EXCEPTION 'created_at is immutable'; END IF;`
         - `RETURN NEW;`
       - Trigger `before_profile_update` BEFORE UPDATE on `public.profiles`.
       - Revoke public execution: `REVOKE ALL ON FUNCTION public.protect_profile_fields() FROM PUBLIC, anon;`

    6. Row Level Security (RLS) Policies on `public.profiles`:
       - `ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;`
       - Public read (SELECT): Allowed for all (`USING (true)`).
       - Insert (INSERT): Gated to matching authenticated user (`WITH CHECK (auth.uid() = id)`).
       - Update (UPDATE): Gated to matching owner (`USING (auth.uid() = id) WITH CHECK (auth.uid() = id)`).
       - Delete (DELETE): Blocked (managed via cascade from `auth.users`).

    7. Sync TypeScript schema types in `src/types/database.types.ts`.
