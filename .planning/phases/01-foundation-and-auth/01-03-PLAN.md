  <action>
    Create `src/context/AuthContext.tsx`:
    1. Listen to Supabase auth events via `supabase.auth.onAuthStateChange`:
       - `INITIAL_SESSION` & `SIGNED_IN`: load user session.
       - **Bounded JIT Profile Self-Healing (Loop Protected)**:
         ```typescript
         const recoveryAttemptedRef = useRef(false);
         // When active user is resolved:
         const { data: profileData, error: profileErr } = await supabase
           .from('profiles')
           .select('*')
           .eq('id', user.id)
           .maybeSingle();

         if (!profileData && !recoveryAttemptedRef.current) {
           recoveryAttemptedRef.current = true; // Guard against infinite loop
           const { data: recovered, error: rpcErr } = await supabase.rpc('ensure_profile_exists');
           if (rpcErr) {
             console.error('Profile JIT recovery failed:', rpcErr);
             setProfileError('Unable to load your profile. Please refresh or retry.');
           } else {
             setProfile(recovered);
           }
         } else if (profileData) {
           setProfile(profileData);
           setProfileError(null);
         }
         ```
       - `SIGNED_OUT`: reset state to null guest state; reset `recoveryAttemptedRef.current = false;`.
       - `PASSWORD_RECOVERY`: trigger `isPasswordRecovery` flag to present password update UI.
       - `USER_UPDATED`: refresh profile state.
    2. Expose auth operations:
       - `signUpWithEmail(email, password, displayName, username)`: returns signup result; flags if email confirmation is required.
       - `signInWithEmail(email, password)`.
       - `signOut()`.
       - `requestPasswordReset(email)`: invokes `supabase.auth.resetPasswordForEmail`.
       - `updatePassword(newPassword)`: invokes `supabase.auth.updateUser({ password })`.
       - `updateProfile({ displayName, bio, websiteUrl, avatarUrl })`: validates that `avatarUrl` and `websiteUrl` use `https://` if present; updates `public.profiles WHERE id = auth.uid()`.
    3. Build `UpdatePasswordModal.tsx` to collect new password when recovery redirect fires.
    4. Wrap `App.tsx` root with `AuthProvider`.
  </action>
